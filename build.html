集計・催促・振り分けはすべて自動。個人で完結するので、リーダーの取りまとめ作業はありません。

準備：Claude と Slack をつなぐ（社長がやること・10分）

この作業だけは、Slack の管理者（多くの会社では社長）にしかできません。 一度つなげば、あとは全部 Claude がやります。

  1. パソコンのブラウザで claude.ai を開いてログインする
  2. 画面左下の自分のアイコンをクリックし、出てきたメニューの「設定」を選ぶ
  3. 左側のメニューから「コネクタ」（外部サービスとの接続窓口）をクリック
  4. 一覧から「Slack」を探して「接続」ボタンをクリック
  5. Slack の画面に切り替わるので、会社のワークスペースを選んで「許可する」を押す （管理者の承認を求める画面が出た場合も、自分が管理者ならそのまま承認できます）
  6. 同じ一覧で「Notion」も「接続」しておく（集計の保存先として使います）
  7. 接続が終わったら、Claude とのチャットで「Slack と Notion をつないだよ。 接続できているか確認して」と送る

接続しても、Claude が勝手に投稿したり読んだりすることはありません。 指示したときだけ動きます。また、Claude がアクセスできる範囲は Slack・Notion 側の権限設定に従います（見えない場所は Claude にも見えません）。

オプション：議事録連携（ToDo付きレター）

すでに議事録ツール（文字起こし・要約・ToDo抽出・PDF共有）をお使いの場合、 レターと連携できます。

  1. 議事録ツールが出した「ToDoリスト（誰が・何を・いつまで）」を Claude が読み取る
  2. 会議の参加者ごとに、Slack のキャンバスで「あなたのToDo」ページを作成・更新する
  3. 金曜17時のレターに、参加者にだけ「あなたのToDo」へのリンクが添えられる
  4. 本人はチェックを付けるだけ。金曜21時の集計でチェック状況を読み取り、 Notion の台帳と週次サマリーに反映する
  5. 未完了のToDoは翌週のレターに自動で繰り越す

キャンバスのチェック状態の自動読み取りは、導入時に動作検証が必要です。 うまく読み取れない場合は、完了したToDoに「済」と返信してもらう方式に切り替えます。

コピペ用プロンプト

① まずはじめに、Slack と Notion を Claude Code につなぐための手順を聞くプロンプトです。ボタンを押してコピーし、ご自身の Claude Code に貼ってください。

ブロック1：準備（Slack と Notion をつなぐ） 
私の会社に「レター」という週次報告の仕組みを作りたい。まず準備を手伝ってほしい。

【やりたいこと】
毎週金曜17時に Slack から全社員へ自動でフォームを送り、回答を Notion に自動で溜める。
社員は Slack しか触らない。Notion を見るのは社長と部門リーダーだけ。

【お願い】
1. Slack の公式 MCP（slackapi/slack-skills-plugin）をこの Claude Code に接続する手順を、
   番号付きで具体的に教えてください。私は非エンジニアなので、
   「どの画面のどこにある何というボタンを押すか」まで書いてください。
   ※ワークスペース管理者の承認が必要なはずなので、その手順も含めてください。
2. Notion の MCP 接続手順も同様にお願いします。
3. 接続できたか確認する方法も教えてください。

② Notion 側に、回答を溜めるための表（データベース）を2つ作ってもらうプロンプトです。

ブロック2：Notion 側を作る 
Notion に、レター用のデータベースを2つ作ってください。

【DB1：週次レポート】閲覧＝社長＋部門リーダー（ゲスト招待）
- 名前（タイトル）
- 部門（セレクト：IT広告 / 飲食）
- 週（日付）
- 調子（セレクト：順調 / 遅れ気味 / 要フォロー）
- 成果物（ファイル&メディア）
- 成果物リンク（URL）
- ひとこと（テキスト）
- 要フォロー（チェックボックス）

【DB2：SOS相談】閲覧＝社長のみ
- 名前（タイトル）
- 週（日付）
- 困りごと（テキスト）
- 求めるもの（セレクト：話を聞いてほしい / 判断・指示がほしい /
  人・お金・時間がほしい / 引き取ってほしい）
- 対応状況（セレクト：未対応 / 対応中 / 完了）
- 社長メモ（テキスト）

【重要】
DB2 は絶対にリーダーへ共有しないでください。
DB1 には要フォローの詳細を一切書かず、「要フォロー」にチェックを入れるだけにしてください。
本音を集めるための設計なので、ここが崩れると仕組み全体が意味を失います。

作り終わったら、2つの DB の URL を教えてください。

③ 毎週金曜21時に自動で動く、集計の指示文です。スケジュール機能（Cowork の定期タスクなど）に登録すれば、社長は何もしなくても Notion に振り分けられ、サマリーが届きます。

ブロック3：毎週の集計（金曜21時に自動実行） 
レターの集計をお願いします。

1. Slack の #レター チャンネルから、今日17時以降にたまった回答をすべて読む
2. 各回答を Notion の「週次レポート」DB に1行ずつ追加する
   - 添付ファイルがあれば、ファイル本体を Notion にアップロードして紐づける
     （Notion の File Upload API を使う。20MBまでは1回で送れる）
   - 調子が 要フォロー の人は、詳細を「週次レポート」には書かず
     「SOS相談」DB へ別途登録し、週次レポート側は「要フォロー」にチェックだけ入れる
3. 未提出者を洗い出す
4. 最後に、社長向けの週次サマリーを1枚にまとめて表示する
   - 提出人数 / 調子の内訳
   - 今週すぐ動いたほうがいいこと
   - 良かったこと
   - 気になる兆候（例：3週連続で成果物の添付がない人）
5. 集計後、統計を Notion の「経営分析」ページに追記してください
   - 提出率／調子の内訳／SOS件数と対応状況
   - 前週までの推移と比べて、気になる兆候があれば1〜3行で書く
   - このページは社長と幹部のみ共有。共有範囲を変えないこと
6. 最後に、回答してくれた人ひとりずつへのお礼DMの文案を作ってください。
   - その人の回答内容を踏まえた、短い労いの言葉にする
   - 評価・採点をしない。ほめ言葉の押し売りもしない
   - 送信はせず、まず私に文案を見せてください。私がOKを出してから送ってください

【注意】
- 社員を評価・採点しない。事実と兆候だけを書く
- 要フォロー の詳細を week レポート側やサマリーの共有部分に漏らさない

※この指示文は「毎週金曜21時に自動実行」する前提です。
   スケジュール登録の方法が分からなければ、まず「この集計を毎週金曜21時に
   自動で実行したい。設定方法を教えて」と Claude に聞いてください。

Slack ワークフローの設定手順

  1. Slack 左サイドバーの「その他」→「自動化」→「ワークフロー」を開く
  2. 右上の「新規ワークフロー」をクリック
  3. 開始方法で「スケジュールされた日時」を選び、毎週金曜17:00・繰り返しを「毎週」に設定
  4. ステップ追加で「メッセージを送信する」を選び、宛先を全社員のチャンネルにして本文を貼る
  5. 「フォームで情報を収集する」ステップを追加し、Q1〜Q3 を作る（Q2 はファイル添付の項目を選ぶ）
  6. 「ユーティリティ」→「分岐を追加」で Q1 = 困ってる・相談したい の条件を作る
  7. その分岐の中に、もう一つフォーム（Q4・Q5）を追加する
  8. 回答の送り先を、非公開チャンネル #レター に設定する
  9. 右上の「公開する」をクリックして完了
  10. リマインド用のワークフローを3本追加する。開始条件はそれぞれ 金曜18:00／19:00／20:00 のスケジュール起動。送り先は全社員のチャンネル。本文： 「レターがまだの方へ：3択（順調でした／ちょっと遅れ気味／困ってる・相談したい）を 選ぶだけでもOKです。30秒で終わります」
  11. チャンネル上部に案内リンクを常設する（ブックマーク） ① #レター チャンネルを開く ② チャンネル名のすぐ下にある「＋」（ブックマークを追加）をクリック ③ 「リンク」を選び、URL欄に https://takishizu-mom.github.io/letter-staff/ を貼る ④ 名前を「レターのご案内」にして保存する → チャンネルの一番上に常にリンクが表示され、流れずに残ります
  12. チャンネルに「レター掲示板」を作る（キャンバス） ① #レター チャンネルの右上にあるキャンバスのボタン（ページのようなアイコン）をクリック ② 開いた白いページに、下の「ブロック4：キャンバス用文面」を貼り付ける → チャットと違って流れない、いつでも見られる掲示板になります

※ Slack の画面表示は更新されることがあります。メニュー名が違う場合は 「ワークフロー」「分岐」で画面内を検索してください。

※ Slack の標準機能では「未回答の人だけ」への自動送信は難しいため、全体向けの リマインドにしています。個別リマインドにしたい場合は、金曜18〜20時にも Claude のスケジュール実行で未回答チェックを走らせる方法があります（上級編）。

④ Slack のキャンバスにそのまま貼る掲示板の文面です。

ブロック4：キャンバス用文面（レター掲示板） 
レター掲示板

毎週金曜17時に、このチャンネルに「レター」が届きます。30秒で終わります。

やることは3つだけ
1. 今週の調子を3つから選ぶ（順調でした／ちょっと遅れ気味／困ってる・相談したい）
2. 作ったもの・出したものがあれば、ファイルかリンクを貼る（無い週は空欄でOK）
3. ひとことあれば書く（任意）

会社からの約束
1. 「困ってる・相談したい」を選んでも、絶対に責めません
2. レターを人事評価に使いません
3. 成果物がない週があっても大丈夫です

リマインドについて
金曜20時まで、1時間ごとにリマインドが届きます。
3択だけでも送ってもらえたら十分です。
送信後のお礼メッセージについて

モックでは毎回ちがう文面が出ますが、Slack のワークフロービルダーだけで これを実現できるかは未確認です。ワークフロービルダーは「条件で分ける」機能 （分岐）はありますが、「ランダムに選ぶ」機能は見当たりません。 【現実的なやり方は2つ】 A. Slack 側は固定文にする（いちばん簡単） 「受け取りました。今週もおつかれさまでした」で固定。 文面は月に一度など、手で書き換えれば十分です。 B. 金曜21時の集計時に、Claude からお礼を送る（おすすめ） Claude Code が各人の回答を読んだうえで、その人に合った労いを individually DM します。 ランダムより気が利きます。「3週続けて成果物を出している人」には その事実に触れた一言を書ける、といったことができます。 ※ 送信前に必ず社長の確認を挟むこと。
