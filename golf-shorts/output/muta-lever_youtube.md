## タイトル

```
右手で叩いても引っかけない打ち方｜テコの「支点」がカギ #ゴルフ #shorts
```

## 説明

```
右手で叩くと左に引っかかる…その原因は「テコ」の使い方にあります。

右を力点にすると、右手を返したときに引っかけやすくなります。
右を支点・左を力点にすると、右で叩いてもフェースが真っ直ぐ戻ってきます。

▼この動画のポイント
・右が支点、左が力点のテコをつくる
・左半身・下半身のきっかけから、右で叩く
・切り返しで胸と骨盤のポジション（センター軸）を変えない
```
